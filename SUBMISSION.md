## Project

- **Title:** CLAD Organizer
- **Theme:** Organize
- **Platform:** SPECS Lens built in Lens Studio with CLAD
- **Creator:** Jayasri Guthula
- **Repository:** https://github.com/jayasrisng/clad-organize

## Description

CLAD Organizer turns a spoken or typed real-world request into a spatial checklist. The Lens supports dinner hosting and chicken biryani planning, then guides the user through a compact spatial market where completing physical items updates the same organizer state.
